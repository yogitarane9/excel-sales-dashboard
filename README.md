# Excel Sales Dashboard

This project showcases an interactive **Sales Dashboard** built in **Microsoft Excel**.  
It demonstrates my ability to clean raw data, structure it for analysis, and create dynamic visualizations to support business decisions.

---

## 🔍 Project Overview

- Cleaned and prepared the raw sales dataset.
- Built pivot tables for different views of the data.
- Designed an interactive dashboard with slicers and charts.

The dashboard helps answer questions like:
- Which product categories generate the most sales?
- How do sales and profit change over time?
- Which states or regions perform best?
- Who are the top customers by profit?

---

## 📂 Files

- `salesdata.csv` – Raw sales dataset.
- `Sales Dashboard.xlsx` – Cleaned data, pivot tables, and final dashboard.
- `Dashboard.jpg` – Screenshot of the final dashboard.

---

## 🧰 Skills & Tools Used

- Microsoft Excel  
- Data cleaning and formatting  
- Pivot tables and pivot charts  
- Slicers and interactive dashboard design  
- Basic KPI reporting (sales, profit, customers, regions)

---

## 🚀 How to Use

1. Download `Sales Dashboard.xlsx`.
2. Open it in Microsoft Excel (desktop recommended).
3. Use slicers and filters to interact with the dashboard and explore the data.
